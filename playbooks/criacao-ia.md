# Criação com IA — Página, Criativo, Imagem e Vídeo

Como usar IA para criar landing page, criativos de anúncio e conteúdo visual em 48h.

## PASSO 1: Estruturar Copy com ChatGPT

### Prompt Estruturado

Usar esse prompt no ChatGPT para gerar copy de LP:

```
Crie uma landing page para vender [OFERTA].

Estrutura (com 10 seções):
1. Hero: headline + subheadline + CTA
2. Problema: 3 situações que ressoam
3. Agitação: custo de NÃO resolver
4. Solução: apresentação do programa
5. Credibilidade: quem sou, por que confiar
6. O que inclui: detalhes do produto
7. Prova social: números + depoimentos
8. Oferta: preço + âncora + bônus
9. Garantia: risco zero
10. FAQ: 5 perguntas + respostas

Público-alvo: [AVATAR]
Tom: [conversacional/formal/descontraído]
Promessa: [PROMESSA PRINCIPAL]
```

**Exemplo:**
```
Crie uma LP para vender um e-book de receitas saudáveis (R$ 27).
Público: mulheres 25-45, saúde, fit
Tom: amiga conversando, motivador
Promessa: "30 receitas de doces saudáveis em 5 minutos"
```

ChatGPT gera estrutura pronta para copiar.

## PASSO 2: Criar Landing Page com Lovable

### Como Usar

1. Abrir **lovable.dev**
2. Clique "Create new project"
3. Cole o prompt de copy do ChatGPT **OU** descreva o que quer

### Prompt para Lovable

```
Crie uma landing page em React com:

Design:
- Hero com imagem grande de [PRODUTO]
- 9 seções de copy [COLE A COPY DO CHATGPT]
- Cores: [cor principal, cor secundária]
- Botões CTA: "Quero [PROMESSA]" (coloridos, grandes)
- Mobile-first (responsivo)

Estrutura HTML/CSS:
- Sem dependências externas
- Tailwind CSS para estilo
- Links: [CTA BUTTON] → [HOTMART LINK]

Extras:
- Adicione mockup do produto (imagem de preview)
- Depoimentos com fotos (se tiver)
- Rodapé com disclaimer
```

### Personalizar Design

Após gerar:
1. Editar cores (hero color, button color)
2. Adicionar logo (canto superior)
3. Upload de imagens (thumbnail do produto)
4. Ajustar typography (fonte maior pra headline)

### Publicar

Lovable oferece URL gratuita: `seu-projeto.lovable.app`

Se quiser domínio próprio (ex: seusite.com):
1. Compre domínio (Hostinger, etc)
2. Configure DNS (Lovable gera instruções)
3. Redireciona em 5 min

## PASSO 3: Criar Imagens com IA

### Opção 1: Canva (Mais fácil)

**Processo:**
1. Abrir Canva
2. Criar novo design → "Landing Page" template
3. Editar: substituir texto por sua copy
4. Adicionar imagem via Canva AI: "create image"
5. Prompt: `"mulher saudável comendo doce saudável, estúdio, luz natural"`
6. Download PNG

**Tempo:** 15 min

### Opção 2: Midjourney (Mais profissional)

**Prompt:**
```
Product photo: healthy sweets assortment, 
studio lighting, clean background, 
high quality, professional product photography
```

**Tempo:** 5 min (geração) + 5 min (refinamento)

### Mockup de Produto

Se não tiver imagem real do produto:

**Canva:** Usar template "Mockup" + inserir imagem gerada
**Resultado:** Parece produto real

## PASSO 4: Criar Criativos de Vídeo (30s)

### Opção 1: CapCut + IA Narração

**Processo:**

1. Abrir CapCut (app/web)
2. Criar novo projeto (vertical, 9:16 para Mobile)
3. Adicionar elementos:
   - **0-3s:** Imagem/vídeo com hook (problema)
   - **3-20s:** Montagem de imagens do produto + texto
   - **20-28s:** Prova social (números + depoimentos)
   - **28-30s:** CTA (botão "clica aqui")

4. Adicionar narração IA:
   - CapCut tem narração via IA (ElevenLabs integrado)
   - Escreve o texto, CapCut gera voz
   - Escolhe voz (masculina, feminina, tom)

5. Adicionar música:
   - CapCut tem biblioteca de royalty-free
   - Escolhe algo "inspirador" ou "energético"

6. Exportar em 4K

**Tempo:** 30 min

### Opção 2: HeyGen (Mais automático)

**Processo:**

1. Abrir heyge.ai
2. Escolher avatar (persona que fala)
3. Cola script em PT-BR
4. HeyGen gera vídeo com avatar falando
5. Adiciona legendas automáticas

**Tempo:** 10 min

## Dicas de IA

### ChatGPT

- Seja **específico** no prompt (público-alvo, tom, tamanho)
- Peça **revisão** ("revise isso pra soar mais amigável")
- Use **variações** ("crie 5 headlines diferentes")

### Lovable

- Comece **simples** (depois complexo)
- Copie a **estrutura**, customize a **aparência**
- Teste **mobile** (90% dos acessos é mobile)

### CapCut

- Hook é tudo (primeiros 3 segundos retêm scroll)
- Voz clara (narração boa > vídeo perfeito)
- Legendas **obrigatórias** (80% assiste sem áudio)

### Canva

- Use **templates** como base (não começa do zero)
- IA Images gera imagem em 30s (não gasta créditos indefinidos)
- Mockups fazem parecer produto real
