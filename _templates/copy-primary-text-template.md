# Template — Primary Text (Meta Ads)

## Framework (Hormozi + Schwartz)

```
LINHA 1 — Hook: problema específico do avatar OU desejo concreto
LINHA 2 — Agitação: por que continua acontecendo (nunca culpar o avatar)
LINHA 3 — Solução: produto + número específico + mecanismo de entrega
LINHA 4 — Garantia + Preço: remove risco, justifica agir agora
LINHA 5 — CTA: um verbo imperativo, uma ação
```

### Regras

- **Linha 1**: máx 125 chars — aparece antes do "ver mais", define se param ou rolam
- **Linhas 2–4**: máx 2 frases cada — brevidade = clareza
- **Números > adjetivos**: "+150 exercícios" bate "muitos exercícios" (Hormozi: especificidade = credibilidade)
- **Agitação sem culpa**: "É falta de X" não "Você não faz X" (Schwartz: mover o mercado, não acusar)
- **Garantia explícita**: sempre incluir prazo — remove risco percebido na decisão de compra
- **Sem hipérbole**: "acesso imediato" > "oportunidade incrível"
- Emoji apenas no CTA, opcional — não dilui o hook

---

## Ângulos disponíveis

| Ângulo | Hook de entrada | Melhor para |
|---|---|---|
| **Dor** | Situação ruim que o avatar vive hoje | Audiência fria que conhece o problema |
| **Transformação** | Resultado que o aluno/atleta/cliente deveria ter | Remarketing ou audiência morna |
| **Micropreço** | Preço + volume de valor | Audiência que compara custo-benefício |
| **Curiosidade** | Pergunta ou dado específico | Teste A/B contra dor |

---

## Estrutura preenchível

```
[HOOK — Situação negativa que o avatar vive / desejo que persiste sem resultado]
[AGITAÇÃO — Por que a situação continua: não é culpa, é falta de X]
[PRODUTO — nome do produto + número principal + como funciona / como entrega]
[VALOR — preço + acesso imediato + garantia de N dias]
[CTA — Verbo imperativo + direção (botão / link) + emoji opcional 👇]
```

---

## Checklist antes de publicar

- [ ] Linha 1 tem menos de 125 caracteres?
- [ ] A palavra "você" (ou "tú") aparece nas primeiras 2 linhas?
- [ ] Há um número específico na linha 3?
- [ ] Preço e garantia estão explícitos?
- [ ] CTA é uma única ação?
- [ ] Sem palavras proibidas Meta (garantia absoluta de resultado, afirmações médicas)?
