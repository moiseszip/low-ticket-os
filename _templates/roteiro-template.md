# Roteiro de Vídeo para Criativos — Template (PT-BR)

## Estrutura Padrão: GANCHO → PROBLEMA → AGITAÇÃO → SOLUÇÃO → CTA

---

## FORMATO 1: UGC (User-Generated Content) — 30 segundos

Estilo "pessoa real falando pro celular". Mobile-first. Simples.

### Gancho (0-2s)

Primeira ação = chamar atenção. Rápido.

**Exemplos:**
- Pessoa acordando cansada na cama
- Close no rosto com expressão de frustração
- Pergunta direta: "Você acorda assim?"

### Problema (2-10s)

Validar a dor. Fazer a pessoa parar o scroll porque se vê ali.

**Exemplo roteirizado:**

```
[PESSOA olha direto pra câmera]

"Acordava 5-6 vezes cada noite. Dormia no máximo 4 horas.

Tentei tudo: remédio, app de meditação, terapia.

Nada funcionava."
```

**Duração:** 8 segundos

### Agitação (10-18s)

Mostrar o custo dessa dor. Amplificar emocional.

```
[Pessoa caminha pela casa, com mau humor]

"Acordava cansado. Irritado com a família.

Perdia metade do dia só porque não dormia.

Minha produtividade era zero."

[Volta para câmera]
```

**Duração:** 8 segundos

### Solução (18-28s)

Reveal: o programa. Rápido, direto.

```
[Pessoa segura celular, mostrando]

"Descobri este método de meditação de 5 minutos.

PRIMEIRA noite: 7 horas de sono.

Agora? Durmo 8 horas todas as noites.

E não preciso de medicamento."
```

**Duração:** 10 segundos

### CTA (28-30s)

Link + ação simples.

```
[Pessoa aponta pra câmera]

"Se você também tem insônia, aqui tem a solução.

Link na bio. Compra hoje."

[Desaparece a tela com link + botão]
```

**Duração:** 2 segundos

## FORMATO 2: VSL (Video Sales Letter) — 60 segundos

Estilo "aula rápida". Mais estruturado. Pode ter B-roll / animações.

### Gancho (0-3s)

Pergunta que ressoа.

```
[TEXTO na tela]
"Você dorme 4-5 horas por noite?"
```

### Problema (3-15s)

Validação + amplificação.

```
[VOICEOVER + B-roll de alguém cansado na cama, acordando]

"A maioria das pessoas que tentam insônia quer dormir mais.

Mas o problema não é querer. É técnica.

Você dorme pouco porque seu corpo não entende como desligar.

Apps genéricos não resolvem isso."
```

### Agitação (15-30s)

Mostrar o custo.

```
[B-roll: pessoa no trabalho cansada, mexendo com família irritada]

"Essa falta de sono? Custa muito:

— 3h de produtividade perdida todo dia (R$ 500/dia se você é profissional)
— Relacionamentos piores
— Sistema imunológico fraco
— Ansiedade crônica"
```

### Solução (30-50s)

Reveal + diferenciação.

```
[Voiceover + animação do programa]

"Existe um método específico para insone crônico.

Não é app genérico.

É meditação de 5-15 minutos que REALMENTE funciona.

1.200+ pessoas já fizeram.

87% dormem melhor em 7 dias."

[DEPOIMENTO — 5s]
"Não acreditava. Primeira noite: 7 horas. Agora: 8 horas." — João
```

### CTA (50-60s)

Urgência + link.

```
[TEXTO na tela + voiceover]

"Preço especial: R$ 97 (sobe em 48h).

Acesso instantâneo.

Garantia de 7 dias.

Link nos comentários / bio."
```

## FORMATO 3: TALKING HEAD — 90 segundos

Estilo "professor explicando". Pode ser você (operador) ou um especialista.

### Gancho (0-5s)

Introdução + crédito.

```
[VOCÊ na câmera, ambiente limpo]

"Oi, sou [Nome]. Dormi 3-4 horas por noite durante 5 anos.

Hoje durmo 8. E quero mostrar por que você também consegue."
```

### Problema (5-25s)

Educação sobre o problema.

```
[Você explica, gesticulando]

"A maioria acha que insônia é:

1) Falta de meditação — não é
2) Fraqueza — não é
3) Falta de medicamento — também não

A verdade? Insônia é um PADRÃO.

Seu corpo aprendeu a não dormir.

E precisa DESAPRENDER.

Não é com apps genéricos que fazem isso."
```

### Solução (25-70s)

Detalhe do programa.

```
[Você continua, com gestos seguros]

"O método é simples: 3 passos.

PASSO 1: Entender por que você não dorme (5 min/dia, dia 1-7)
PASSO 2: Retreinar seu corpo (meditações + checklist, dia 7-21)
PASSO 3: Automatizar sono (hábito formado, dia 21-30)

Resultado? Você dorme 8 horas.

Sem medicamento. Sem terapia cara.

Prova? 87% dos meus alunos dormem bem em 7 dias."
```

### Social Proof (70-85s)

Depoimento inserido.

```
[VÍDEO depoimento curto — 10s]

OU

[Você fala enquanto prints de reviews passam]

"Veja só esses reviews. Pessoas reais. Resultados reais."
```

### CTA (85-90s)

Call to action final.

```
[Você aponta pra câmera]

"Se você também tem insônia, não deixa pra depois.

Turma abre 1x por mês. Próxima: 31 de maio, 50 vagas.

47 pessoas já se inscreveram.

Não deixa fechar. Link aqui."

[Texto com link/botão]
```

## Checklist de Roteiro

- [ ] Gancho interessante (primeiros 3-5s retêm scroll)
- [ ] Problema específico (não "saúde geral", "insônia crônica")
- [ ] Agitação clara (custo emocional + financeiro)
- [ ] Solução diferenciada (por que NÃO é app genérico?)
- [ ] Prova social (números + depoimento)
- [ ] CTA claro (link + ação + urgência)
- [ ] Timing respeitado (30s / 60s / 90s exatos)

## Dicas de Produção

1. **Lanterna de frente** (não fundos) — ilumina o rosto bem
2. **Áudio limpo** — mais importante que vídeo perfeito
3. **Fundo simples** — seu rosto é o foco
4. **Olhe pra câmera** — não pros lados
5. **Não leia script** — converse, como se falasse com amigo
6. **Corte frames mortos** — começa logo com o gancho
7. **Legendas** — 80% assiste sem som
